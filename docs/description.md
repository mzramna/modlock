## Long description (EN)

**ModLock turns "which mods can I use?" into part of the game.**

Every player starts with only the mods you allow. The rest stay locked: their items can't be crafted by hand until the player unlocks them. A bundle can unlock Create *and every Create addon installed on the server*. Players can pick their starting mods on a choice screen, receive them from quests or admins, or get them through their RP class.

- 🔒 Per-mod crafting lock: crafting table, 2x2 grid, smithing table, stonecutter and furnaces.
- 📦 Mod bundles: one JSON file unlocks a mod and all its addons, detected automatically.
- 🎭 RP classes with restricted and closed bundles.
- 🖼️ Starting choice screen with pictures, descriptions and optional exclusivity.
- ⚙️ Machines, automation and hoppers are never blocked, so the mod is light and compatible with big packs like ATM10 and ATM11.

Install it on the server and on every client. Supported: NeoForge 1.21.1 and 26.1.2.

## Descrição longa (PT)

**O ModLock transforma "quais mods eu posso usar?" em parte do jogo.**

Cada jogador começa só com os mods que você permitir. O resto fica bloqueado: os itens não podem ser craftados à mão até o jogador liberar o mod. Um pacote pode liberar o Create *e todos os addons do Create instalados no servidor*. O jogador pode escolher os mods iniciais numa tela de escolha, recebê-los por quests ou pelos admins, ou ganhá-los pela classe de RP.

- 🔒 Bloqueio de craft por mod: mesa de craft, grade 2x2, mesa de ferraria, cortador de pedras e fornalhas.
- 📦 Pacotes de mods: um arquivo JSON libera um mod e todos os addons dele, detectados sozinhos.
- 🎭 Classes de RP com pacotes restritos e fechados.
- 🖼️ Tela de escolha inicial com imagens, descrições e exclusividade opcional.
- ⚙️ Máquinas, automação e funis nunca são bloqueados, então o mod é leve e compatível com packs grandes como ATM10 e ATM11.

Instale no servidor e em todos os clientes. Suporte: NeoForge 1.21.1 e 26.1.2.
